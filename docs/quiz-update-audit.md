# 3回チャレンジ・追加ヒント・難易度再分類 監査記録

## データ監査

- 対象: 100匹
- 追加ヒント①設定済み: 100匹
- 追加ヒント①未設定: 0匹
- 追加ヒント①への正解名混入: 0匹
- 既存ヒント3つ・豆知識との完全一致: 0匹
- 単語集合による類似候補（共通率34%以上）: 0匹
- 追加ヒント①の最長文字数: 28文字
- 4択重複: 0問
- 正解が4択内に1つ以外: 0問

追加ヒント①は全件を個別に作成し、既存ヒント3つと豆知識とは別の特徴になるよう目視確認した。希少動物や判別が難しい特徴は、動物園・博物館・公的機関の資料で確認した。

## 実装時の不変条件

アプリのデータ初期化時に、次を自動検証する。

- メタデータが100匹分あること
- 追加ヒント①が空でないこと
- 追加ヒント①に正解名が含まれないこと
- 追加ヒント①が既存ヒント・豆知識と完全一致しないこと
- 難易度別の件数が50 / 25 / 15 / 10であること
- 各問題の4択がすべて異なり、正解を1つだけ含むこと
