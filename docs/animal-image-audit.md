# 動物画像100匹 監査結果

## 監査概要

- 対象: 17枚の3×2スプライトシート、全100匹
- 監査方法: 原画像を実寸表示し、各動物の不透明領域と512pxセル境界を照合。左右・上下の中心差が20pxを超える場合を位置調整対象とした。
- 問題なし: 63匹
- 修正対象: 37匹
- セル境界越え: 5匹（サイ、ワニ、ラクダ、ウマ、ウサギ）
- 隣接動物の映り込みが発生するセル: カバ、サイ、ブタ

## 修正方針

スプライトの背景位置を個別にずらす方式では、セルをまたぐ動物の欠けと隣接動物の映り込みを同時に解消できない。そこで全100匹を原画像から個別ファイルへ分離し、透明な512×512pxキャンバスの中央へ配置した。共通の `AnimalArt` は個別画像を `background-size: contain`、`background-position: center` で表示する。

この方式により、正解発表、図鑑一覧、図鑑詳細、トップ画面、メダル演出のすべてへ同じ補正が反映される。
